# NT Medic Assistant

Помощник медика для **Barotrauma + Neurotrauma**.

### Возможности
- Подсказки по лечению и подсветка медикаментов.
- Пошаговые инструкции для операций.
- Журнал пациентов и их состояния.
- Поиск медикаментов на подлодке.
- Анализ генов и создание донорских карт.

### Установка и запуск

1. Установите [Neurotrauma](https://steamcommunity.com/sharedfiles/filedetails/?id=3190189044) и [LuaCs](https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234).
2. Скачайте NT Medic Assistant.
3. **Linux / Steam Proton:** откройте терминал в папке мода и выполните:
   `bash tools/install-local.sh`
4. Запустите Barotrauma с установленными зависимостями.
5. Откройте окно здоровья пациента и введите в игровую консоль `ntma`.

### Команды
- `ntma` - открыть/скрыть панель.
- `ntma reset` - сбросить положение панели.

**Важно:** после обновления игры или Neurotrauma может потребоваться повторная установка через скрипт.
